Switchboard Server

Room profiles for your X4 Pro remotes

    switchboard.local

    ⚡ Flash an X4 Pro remote

    Select a room profile on the left, or create a new one.

    Each profile covers a room's name, description, Home Assistant connection, Standby screen settings, Climate sensors, Lighting, Blinds, Media, and TV. Any X4 Pro remote on this network can pull one of these profiles from Settings → Configuration → Load from home server, instead of entering it by hand.

    WiFi and a default Home Assistant connection live under Globals in the sidebar and are shared by every room — a room only needs its own Home Assistant connection if it switches that on for itself.

    Active screens

    Which on-device carousel screens this room actually has — unchecked ones are skipped instead of showing up empty or non-functional. Just an on/off flag for each; Climate isn't configured here (still on-device only), and this doesn't hide or affect the Lighting/Blinds/Media/TV/Xbox cards below.

    Quick Access hub

    The device's home/launcher screen. Each button's top two-thirds opens a screen below; its bottom third fires a quick action without leaving the hub — turn "Quick actions" off to hide that bottom-third zone everywhere on this device. Up to 10 items show per hub screen.

    Home Assistant connection

    This room uses the connection configured under . Switch off "Use global connection" to give this room its own Home Assistant host, port, and token instead.

    Standby

    The deep-sleep dashboard screen — date, weather, and indoor temperature, shown on wake and refreshed on a timer.

    Climate

    The main temperature sensor for this room's Climate screen, plus any additional ones to show alongside it (one per floor, one near a window, and so on). Read-only display data, so there's nothing else to configure per sensor.

    Lighting

    A whole-room group control, any number of individual lights, and one-tap Home Assistant scene shortcuts. On/off is always available — tick only the extra controls each light or the group actually supports.

    Blinds

    A whole-room group control plus any number of individual blinds. Every blind (and the group) gets Open / Close / Stop — no extra controls to set up here, since Stop already doubles as "go to favorite position" on real cover hardware/Home Assistant once the blind isn't moving.

    Media

    The entity behind this room's on-device Music screen — usually the household's Spotify Connect player. Its own Home Assistant capabilities (play/pause, next/previous, volume, and so on) carry over automatically; nothing else to configure here.

    Player

    TV

    This room's Android TV device. Standard controls — D-pad, Home/Back, volume, play/pause — come from the two entities' own Home Assistant capabilities, nothing to configure here; just wire up where to launch YouTube, Netflix, and TV mate.

    Apps

    Each app's launch value is whatever the remote entity's launch/activity command expects — usually an Android package name (e.g. com.google.android.youtube.tv).

    Xbox

    This room's Xbox console. Power and now-playing state come from the two entities' own Home Assistant capabilities, nothing to configure here — just wire up the console and its game library. The now-playing hero art on-device is read live from the media player entity, not stored here; each game's own art below is only for its library row, and only used when the list source is "Configured list" (in "Browse from console" mode, row thumbnails come from Home Assistant's browse_media instead).
